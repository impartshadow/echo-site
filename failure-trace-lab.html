## Root-cause chain

1. Surface: scaffold tokens ([System: Bot just restarted...], [Channel: ...]) repeatedly stripped from outbound Discord messages by egress sanitization
2. The identical four leak shapes recur across six sweeps — sanitization is succeeding but never converging, because it operates at the sink
3. The restart preamble is injected into the model's prompt context by the messaging layer on every bot restart, and the model faithfully echoes framing it was shown
4. No ingress-side contract strips or fences scaffold framing at prompt-assembly time, so every restart regenerates the leak and re-taxes the egress guard
5. The 12:40:14 triple-block and 15:27 verification-verb block share the same structural cause: the agent generates artifacts (state writes, receipts, verification claims) from internal narrative rather than from tool-grounded reality, and only sink-side deterministic gates stand between that narrative and the owner

## The contract that would have caught it

**`scaffold-ingress-fence`**

- **Trigger:** Prompt/context assembly for any model turn that includes system-injected framing (restart notices, channel headers, harness status lines)
- **Precondition:** All harness scaffold tokens must be wrapped in a fenced, non-echoable delimiter (or stripped entirely) before entering model context; any scaffold token appearing unfenced in assembled context is a violation at assembly time, not at egress
- **Why it catches this:** Every FM-005 event in this window is the model echoing framing the messaging layer showed it. Fencing at ingress removes the leak's source, so the egress guard becomes a rarely-fired backstop instead of a six-per-window mop. The recurrence pattern proves egress-only enforcement never converges on this failure class.

## Why this matters

Every one of these six violations — PII in a file write, a nonexistent commit hash cited as a receipt, an unresolvable Discord recipient, an unprovenance 'verified' — was blocked deterministically at the tool boundary, not by asking the model to behave. A prompt-only guardrail had already lost each of these fights: the model confidently generated the fake hash and the verification verb despite standing instructions against exactly that. The lesson cuts both ways, though: the six-fold repetition of identical scaffold leaks shows that sink-side enforcement without a source-side fix becomes a permanent runtime tax — mature governance means guards that both block the bad output and drive an upstream change that makes the guard stop firing.
