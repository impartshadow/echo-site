## Root-cause chain

1. Surface: Discord messages to #shadow-hq contain harness restart banners and channel-routing headers; one message is 100% scaffold.
2. The egress guard strips matched tokens post-hoc, so Will sees clean output and no pressure exists to fix anything upstream.
3. The restart banner ('[System: Bot just restarted. Completed before restart: ...]') is injected into the model's input context as plain text with no provenance marker, so the model treats it as message content to relay.
4. Because the injection recurs on every restart and nothing changes the prompt or the injection format, the identical 4-leak pattern replays every cycle — the guard fires 16 times on 4 distinct shapes with zero learning.
5. The model has begun paraphrasing the banner ('Bot just restarted: previous task was...'), showing it has internalized scaffold as legitimate content — a drift the token matcher only accidentally still catches.
6. Structural cause: sanitization at the sink instead of provenance-tagging (or stripping) at the source, plus a taxonomy gap — no FM exists for scaffold-echo, so the events are miscoded as FM-005 and the recurrence is invisible to failure-mode frequency tracking.

## The contract that would have caught it

**`scaffold-ingress-quarantine`**

- **Trigger:** Any harness-injected context block (restart banners, channel headers, '[System: ...]' frames) entering the model's input on process start or message dispatch.
- **Precondition:** Scaffold text must be either stripped before model ingestion or wrapped in a provenance envelope the model is contractually barred from reproducing; a paired egress check asserts zero envelope-derived n-grams (not just literal tokens) in outbound text, and blocks any send whose post-sanitization body is empty.
- **Why it catches this:** It attacks the source: the banner never reaches the model as echoable content, so all 16 egress firings — including the paraphrased 'Bot just restarted:' variant that a token list only caught by luck, and the empty-after-sanitization send — become impossible rather than repeatedly cleaned up. The 4x identical cycle proves the current guard prevents exposure but not recurrence.

## Why this matters

Every one of the 16 scaffold leaks in this window was caught and neutralized deterministically — including a paraphrased variant and a message that was 100% metadata — which is exactly what prompt-only guardrails cannot promise, since the model demonstrably re-leaked the identical content four cycles in a row despite whatever instructions it carries. But the trace also shows the limit of sink-side enforcement: deterministic contracts stop the bleeding without healing the wound, and the mislabeled FM-005 tags show that without accurate failure taxonomy, even perfect enforcement produces telemetry that hides the real defect. The value proposition is the pairing: contracts guarantee containment on every single event, and the resulting structured trace is what makes a root-cause fix (ingress quarantine) findable at all.
