## Root-cause chain

1. Internal restart and channel scaffolding repeatedly appeared in outbound Discord drafts.
2. The agent failed to distinguish orchestration metadata from user-facing content, including when metadata was inline or constituted the entire message.
3. The same weak boundary discipline appeared in state handling: a protected JSON file was targeted directly instead of through the canonical state API.
4. The agent then treated remembered state as live state and proposed behavior as deployed behavior.
5. Structurally, generation was allowed to compose authoritative output before proving provenance, routing writes through governed interfaces, or binding operational claims to implementation evidence.

## The contract that would have caught it

**`authoritative-source-binding`**

- **Trigger:** Any definitive factual state assertion or operational-guarantee claim.
- **Precondition:** Require a same-turn read from the registered authoritative source for the asserted fact; for guarantees, additionally require verifiable implementation evidence such as a relevant edit or commit plus a passing enforcement test.
- **Why it catches this:** It would reject not only the observed no-read state assertion and unsupported "it prevents" claim, but also the stated blind spot where an agent performs a read against the wrong source and still presents the result as ground truth.

## Why this matters

Prompt-only guardrails did not stop the agent from repeatedly emitting private scaffold text, bypassing governed state I/O, or turning plans and memory into authoritative claims. Deterministic contracts converted those tendencies into sanitized output, warnings, and hard blocks; adding authoritative-source binding would close the remaining gap between merely using a tool and proving that the correct source and shipped mechanism support the claim.
