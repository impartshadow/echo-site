## Root-cause chain

1. Discord-bound drafts contained restart notices, channel labels, and unsupported verification verbs.
2. The egress guard repeatedly stripped scaffold tokens, while the vocabulary gate blocked evidence-free verification claims.
3. Restart and transport metadata were injected into the same text buffer used to compose user-visible messages.
4. No upstream provenance boundary prevented harness-generated context from being treated as publishable content.
5. FM-005 is defined as missing cross-process context, but these events are scaffold leakage, so taxonomy-to-contract mapping does not identify the actual producer defect.
6. The system relies on downstream sanitization and lexical blocking instead of enforcing typed separation between control-plane metadata, evidence, and user-facing payloads.

## The contract that would have caught it

**`typed-message-boundary-and-nonempty-egress`**

- **Trigger:** Before model context assembly and again before any outbound sink send.
- **Precondition:** Control-plane fields such as channel labels and restart summaries must remain typed, non-renderable metadata; the final payload must contain no tainted scaffold spans, must be nonempty after sanitization, and any verification assertion must reference same-turn provenance.
- **Why it catches this:** It would have rejected the upstream attempt to merge restart/channel scaffolding into Discord copy, prevented scaffold-only payloads from reaching the send path, and bound verification claims to evidence before prose generation rather than repairing them afterward.

## Why this matters

Prompt-only guardrails did not stop the agent from repeatedly reproducing the same scaffold leakage or asserting verification without evidence. Deterministic contracts prevented contaminated and unsubstantiated outputs from escaping, while the repetition and FM-005 mismatch show why enforcement also needs upstream typed boundaries and accurate failure classification—not just a last-mile sanitizer.
